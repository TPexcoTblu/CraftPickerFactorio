# Craft Picker Factorio

Craft Picker is a QoL mod for Factorio 2.0 that lets you point at a placed entity and queue the matching item for hand crafting with a hotkey.

## Features

- Craft the selected placed entity with one input.
- Supports entity ghosts.
- Resolves items through prototype `place_result`, so it works with modded entities when their prototypes are defined normally.
- Optional fallback through minable products.
- Runtime per-player settings for amount, ghosts, messages, fallback, and force filtering.
- Separate controls for crafting one configured amount, 5, or the maximum possible amount.

## Default Controls

- `Mouse button 3`: craft configured amount.
- `Shift + Mouse button 3`: craft 5.
- `Control + Mouse button 3`: craft maximum possible.

All controls can be changed in Factorio controls settings.

## Compatibility

- Factorio 2.0
- Space Age compatible by prototype-driven behavior
